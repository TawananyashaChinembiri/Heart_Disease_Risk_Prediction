# ❤️ Heart Disease Risk Prediction — Machine Learning with Explainable AI

An end-to-end pipeline that predicts the presence of heart disease from 13 clinical features, explains each prediction with **SHAP** and **LIME**, and serves the model through a **Streamlit** web interface.

**Author:** Tawananyasha Nigel Chinembiri (R223784U) — BSc Honours Data Science and Informatics, University of Zimbabwe, Department of Analytics and Informatics  
**Supervisor:** Mr. Zimowa

> ⚠️ Academic prototype trained on a public dataset. It is **not** a medical device and must not be used for diagnosis or treatment decisions.

pip install -r requirements.txt

Trained artefacts are already included, so step 1 is optional. The pickled models were produced with the library versions in `requirements.txt`; use those versions (or re-run the notebook) to avoid pickle-compatibility warnings.

## Pipeline

| # | Stage | Details |
|---|-------|---------|
| 1 | Data loading & cleaning | 1,025 rows → **302 unique patients** after removing 723 duplicates; no missing values |
| 2 | EDA | Distributions, class balance, categorical effects, correlations, violin/box plots, pairplot |
| 3 | Split | Stratified 80/20 train/test, `random_state=42` |
| 4 | Feature engineering | `hr_percent = thalach / (220 − age)`, `age_oldpeak = age × oldpeak` |
| 5 | Class balancing & scaling | SMOTE on the **training split only**; `StandardScaler` fitted on training data, applied to test |
| 6 | Feature selection | RFECV (Random Forest, 5-fold, AUC) |
| 7 | Modelling | Grid-search tuned Logistic Regression, Random Forest, XGBoost, SVM |
| 8 | Ensemble | Stacking (RF + XGBoost + SVM) with a Logistic Regression meta-learner |
| 9 | Evaluation | Accuracy, precision, recall, F1, AUC-ROC, MCC, ROC/PR curves, confusion matrices |
| 10 | Explainability | SHAP (summary, bar, dependence, waterfall), LIME (high- and low-risk cases) |
| 11 | Actionable explanations | SHAP contributions mapped to clinical next steps (risk-increasing factors only) |

## Streamlit interface

* Animated hero banner, risk gauge and recommendation cards (pure CSS/SVG, no extra dependencies).
* **Risk assessment** — enter patient details in the sidebar; get the predicted probability from the stacking model, a SHAP waterfall plot and recommendations for each risk-increasing factor.
* **Model performance** — metrics table, ROC/PR curves and global SHAP plots.
* **About** — dataset and pipeline summary.

The headline probability comes from the stacking model; SHAP explanations are computed on its XGBoost component (a tree model SHAP can explain exactly).

## Limitations

* **Small test set:** with ~61 test patients, one misclassification shifts accuracy by ≈1.6 percentage points.
* **Optimistic CV:** SMOTE, scaling and RFECV are fitted before cross-validation, so CV AUC (~0.91–0.92) overstates performance; the held-out test AUC (~0.82–0.86) is the reliable figure.
* **Dataset coding:** in this Kaggle copy several codings run opposite to the textbook UCI description (e.g. `ca = 0` and male sex are associated with lower disease probability). Explanations describe what the model learned from this data, not established clinical facts.
* RFECV retained all 15 features, so no feature was dropped.
